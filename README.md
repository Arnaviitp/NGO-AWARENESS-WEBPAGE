# NGO-AWARENESS-WEBPAGE
🌟 InAmigos Foundation - Awareness WebpageA responsive, single-page website designed to spread awareness about the initiatives, projects, and impact of the InAmigos Foundation, a youth-led Non-Governmental Organization (NGO).🎯 ObjectiveThis project aims to provide a clean, engaging, and informative digital presence for the NGO. It is built to encourage users to join as volunteers, donate to the cause, and spread the word across social media.✨ Features📱 Fully Responsive Design: Adapts beautifully to mobile phones, tablets, and desktop screens using CSS Flexbox and Grid.🎨 Modern UI/UX: Clean typography, consistent color themes (Deep Blue & Vibrant Orange), and ample whitespace.🖱️ Interactive Elements:Sticky Navigation Bar: Features a glass-morphism (blur) effect when scrolling down.Smooth Scrolling: Native CSS smooth scrolling for all internal page links.Animated Impact Counters: Numbers dynamically count up from zero when the "Real-World Impact" section scrolls into view (using JavaScript IntersectionObserver).Hover Effects: Interactive image gallery and project cards with scaling and overlay animations.🔔 Custom Notifications: Replaces standard browser alerts with a sleek, animated "Toast" notification when users click "Spread Awareness" (copies the link to their clipboard).⬆️ Scroll-to-Top: A floating action button that appears dynamically as users scroll down the page.🔗 Social Integration: Footer contains direct links to the official InAmigos Foundation social media profiles.🛠️ Technologies UsedThis project was built focusing on pure, vanilla web technologies without the overhead of heavy frameworks:HTML5: Semantic structuring of the webpage.CSS3: Styling, animations (@keyframes), CSS variables for easy theming, Grid, and Flexbox layouts.JavaScript (Vanilla): DOM manipulation, mobile menu toggling, clipboard API integration, and scroll observers.FontAwesome (v6.0.0): For scalable vector icons.Unsplash: High-quality, royalty-free placeholder imagery.📂 Project StructureFor maximum simplicity and easy deployment, the entire project is contained within a single file:├── index.html       # Contains all HTML, inline <style> CSS, and inline <script> JS
└── README.md        # Project documentation
🚀 How to Run LocallyBecause this project uses standard web technologies and no build tools or servers are required, viewing the website is incredibly simple:Download or clone the repository to your local machine.Locate the index.html file.Double-click the file to open it in your default web browser (Chrome, Firefox, Safari, Edge, etc.).✏️ How to CustomizeIf you wish to adapt this template for another project or update the content:Colors: Modify the --primary-color and --secondary-color variables at the very top of the <style> tag in the :root pseudo-class.Images: Search for the <img> tags and replace the src attribute URLs with your own image links.Social Links: Scroll to the <footer> section and update the href attributes in the .social-links div to point to your specific profiles.Impact Numbers: To change the target numbers for the animated counters, find the <span class="counter" data-target="YOUR_NUMBER">0</span> elements in the HTML and change the data-target value.🤝 AcknowledgmentsDesign inspiration and content structure based on the official InAmigos Foundation mission.Icons provided by FontAwesome.Placeholder photography provided by the talented creators on Unsplash.
